# Asset provenance record

This file records the source category of every visual or audio asset shipped by version 1. It is an engineering inventory, not a legal opinion. Before store submission, Thoughtless Labs should retain the original generation records, confirm the applicable tool terms, and have the publisher's legal owner approve the archive.

## Fonts, icons, sound, and feedback

- The game bundles no font files. Runtime typography uses platform system families defined in `src/styles.css`.
- Interface symbols come from the `lucide-react` package recorded in `pnpm-lock.yaml`; preserve its package license with the release dependency archive.
- Sound cues are synthesized at runtime with the Web Audio API. No music or sound-effect recording is bundled.
- Native haptics use the official Capacitor Haptics plugin; browser vibration is used only when available and enabled.
- The Google feature graphic currently renders its title with host system fonts. Generate and visually approve the final PNG on the recorded release machine; the PNG, rather than the host font, is the submitted artifact.

## Release archive

For every store build, archive:

1. The exact Git commit and `pnpm-lock.yaml`.
2. Original image-generation outputs and prompt/session records retained by the publisher.
3. SHA-256 hashes for `public/assets/`, `assets/`, and the submitted store files.
4. The signed native binaries and the exact screenshots captured from them.
5. Package-license output for the locked production dependency graph.
6. Written publisher approval for the icon, portraits, card back, copy, fonts, and screenshots.

One portable hash command is:

```sh
find public/assets assets store-assets -type f -print0 | sort -z | xargs -0 shasum -a 256
```

Do not present placeholder Android-derived images as iPhone screenshots. The asset generator emits App Store screenshots only when all three verified native iPhone inputs are provided.
